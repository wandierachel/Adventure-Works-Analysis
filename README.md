# AdventureWorks Sales Analysis - Power BI Dashboard 
## Project Overview
This project is an end-to-end Power BI business intelligence dashboard designed for **AdventureWorks**, a fictional manufacturer of bicycles and cycling accessories. The report transforms raw sales, product, and customer data into an interactive, two-page dashboard. It is built to help stakeholders track high-level financial performance, analyze product profitability, and understand customer purchasing behavior. 
## Dashboard Pages & Features ### 
1. Executive Dashboard Summary The first page serves as the financial anchor, designed for C-suite executives to grasp company performance at a glance. *   **Key Performance Indicators (KPIs):** Total Revenue ($24.91M), Total Profit ($10.46M), Profit Margin % (41.97%), and Revenue YoY Growth % (58.40%). *   **Performance Trends:** A line chart plotting Total Revenue by Year (2015–2017).
 * **Product Profitability:** Bar charts breaking down Total Revenue, Total Cost, and Profit Margin % by Product Category.
